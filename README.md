# pca-japan-prefectures
47都道府県の産業構造と人口動態に関するPCA


# 都道府県のクラスター分析

多変量分析の講義で行ったRを利用した都道府県のクラスター分析を、Pythonで作り直したものです。

## 内容
47都道府県を、産業構造（第1次・第2次産業就業者比率）、人口密度、人口1人あたり延べ宿泊者数の4つの数字で分類しました。対数変換と標準化のあと、k-means（k=4）で分け、主成分分析で可視化し、Ward法と比較しました。対数変換をしない場合との比較も行っています。

## 結果の要約
- 4グループ：都市圏型（8県）、製造業型（17県）、農業・低密度型（20県）、京都・沖縄（2県）。グループ名は、グループ別の平均を見て付けた解釈です。
- Ward法との一致度（ARI）は0.79。宮城・山梨・長野の3県は、手法で分類が変わりました。
- 対数変換をしないと、東京・神奈川・大阪の3県が、1つのグループになりました（一致度0.72）。
- 第3次産業比率は多重共線性を避ける目的で除外しました。
- シルエット係数は0.35で、グループの分離は弱くなっています。道府県の境界線は明確に分かれるものではなく連続的であることを示しています。

## データ
| 変数 | 出典 | 年 |
|---|---|---|
| 第1次・第2次産業就業者比率 | e-Stat 国勢調査（不詳補完値の参考表、表番号5-2020） | 2020年 |
| 総人口・可住地面積当たり人口密度 | e-Stat 社会・人口統計体系 | 2020年 |
| 延べ宿泊者数 | 観光庁 宿泊旅行統計調査 推移表 | 2019年 |

URLと取得日は、ノートブック「2. データの出典」に記載しています。

## 限界
47県・4変数で、結果は変数の選び方に依存します。2府県はグループとして一般化できませんでした。延べ宿泊者数は、観光と出張を区別できません。年次は、産業・人口が2020年、宿泊が2019年で、1年ずれています。詳しくは、ノートブックの9. 考察と限界を参照してください。
